# Консольное приложение для учета студентов (Kotlin)

Учебный проект консольной системы для автоматизации работы с данными студентов колледжа, их успеваемостью и расчета академической статистики.

## 🛠 Стек технологий
* **Язык программирования:** Kotlin
* **Коллекции:** ArrayList
* **Работа с данными:** File I/O (сохранение и загрузка базы данных через форматы TXT/CSV)
* **Парадигма:** Объектно-ориентированное программирование (ООП)

## 🚀 Реализованный функционал
* **Полный CRUD-цикл:** создание, просмотр, редактирование и удаление профилей студентов по ID.
* **Фильтрация и поиск:** продвинутый многопараметрический поиск по учебной группе, уникальному идентификатору и диапазону оценок.
* **Аналитический модуль:** автоматический расчет среднего балла, выявление академических лидеров и отстающих студентов.
* **Надежность:** валидация входящих данных от пользователя и безопасная обработка исключений (try-catch).
